# CodeNote

CodeNote is a DRS-governed Tauri desktop editor with live markdown preview, Prism highlighting, Mermaid diagrams, tabs, and an optional terminal drawer.

The existing `README.md` and `SPEC.md` remain the detailed product and rendering contract. This file is the standard project front door for agent onboarding and audit tooling.

## Current Posture

- Standard: DRS, with WGS, PPS, and Blue Slate support.
- Stage: prototype.
- Verification: metadata reconciled on 2026-07-25; build, test, artifact, and release state were not reverified during this audit.
